# Tech context

Bun (server and tooling), React 19 with the React Compiler, TypeScript, SQLite (`.tmp/dev.db`) or Postgres, MCP. `bun run dev` serves the admin on :5173 and the API on :3001.

`origin` is the fork. The engine repository recorded in `package.json` is `corebunch/instatic`. Do not push to `main`.

Design tokens are generated by `design-system/gen.py` into `tokens.css` (`--k-*`). `src/styles/globals.css` imports that file. Fake glass is `src/styles/materials.css` plus `data-k-material`.

Tooling:

- `bun run lint:unused` — knip. Config: `knip.json`.
- `bun run size` — size-limit, gzip, on `dist/assets/AdminCanvasEditorBody-*.js`, budget 300 KB. Run `bun run build` first.
- `bun run analyze` — Vite build with `ANALYZE=1` and `rollup-plugin-visualizer`, writing `dist/stats.html`.
- `react-scan` is imported from `src/admin/main.tsx` only when `import.meta.env.DEV` is true.

Cursor memory MCP is `.cursor/mcp.json` (`@modelcontextprotocol/server-memory` via npx). Its graph file `docs/memory/knowledge-graph.jsonl` is gitignored.
