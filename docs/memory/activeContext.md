# Active context

Focus: Phase 3 is stacked on the Phase 2 command branch. The Keijam shell has Design, Animate, and Code. Code components are parsed TSX with property controls. Animate edits a state machine and exports CSS or a small Web Animations runner. WebGL, Three.js, and GSAP load only when a layer uses them. `keijam_generate_component` writes a component from a description.

Next: install the official logo, replace pixel-art icons with monochrome Lucide (16px, stroke 1.5, `currentColor`), and build the Pages / Layers / Assets plus the rest of the Framer inspector (grid, gap and padding handles, inline text). One agent command is still several undo steps when it writes a node and then its class. Property controls are the string, number, boolean, color, and enum subset. Richer Framer controls (font, file, array, component instance) are not parsed yet.
