# Project brief

Keijam is a visual web design tool, forked from Instatic (MIT). It aims at a Framer-like workflow with Figma UI3 density: neutral grays, one blue accent, Lucide icons. The owner is selling a self-hosted product. Published pages stay plain HTML and CSS.

Phase 1 scope: rebrand; a Layers / canvas / properties shell; zoom and pan; free drag, resize, snapping, and smart guides; stack versus absolute layout with Fixed / Fill / Fit; breakpoint overrides; basic hover and press.

The engine underneath (auth, data tables, plugins, publish) stays the Instatic server. New dependencies must be MIT, ISC, BSD, or Apache-2.0. Revyme and Webstudio are AGPL and are reference only.
